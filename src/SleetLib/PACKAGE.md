# SleetLib

SleetLib is the library behind the [Sleet](https://www.nuget.org/packages/Sleet) command line tool. Use it to create and update static NuGet feeds on Azure Storage, Amazon S3, S3-compatible storage, or a local folder from your own .NET code. Each Sleet command has a matching API, such as `PushCommand.RunAsync`.

To manage feeds from a terminal or CI, install the Sleet .NET tool instead:

```
dotnet tool install -g sleet
```
